# bug-farm-cloud-infra

Мульти-облачная инфраструктура для платформы **bug-farm.xyz**. 

Репозиторий содержит IaC-код (Terraform) и конфигурации операционной системы **Talos Linux** для разворачивания самоуправляемых Kubernetes-кластеров в различных облачных провайдерах.

## 🏗 Архитектурные принципы

* **Cloud-Agnostic:** Платформа не привязана к проприетарным сервисам конкретного облака (GKE/EKS). Облако используется исключительно как IaaS-провайдер «сырых» виртуальных машин и сетевой инфраструктуры.
* **Talos Linux:** В качестве операционной системы нод используется минималистичная, полностью декларативная ОС без SSH и классического shell, управляемая строго через API (`talosctl`).
* **Zero Trust & Private-First:** Все виртуалки разворачиваются в приватных подсетях без публичных IP-адресов. Доступ к API управления (Talos/K8s) осуществляется через GCP IAP Tunnel / Bastion.
* **Encrypted Secrets:** Конфигурации нод и ключи шифруются «на лету» с помощью **SOPS + age** и хранятся прямо в Git.

## 📁 Структура репозитория

```text
bug-farm-cloud-infra/
├── platforms/                  # IaC-код под конкретные облака
│   ├── gcp/                    # Google Cloud Platform (VPC, Compute Engine)
│   └── aws/                    # Amazon Web Services (заготовка)
├── talos/                      # Конфигурации и манифесты ОС Talos (SOPS)
└── scripts/                    # Вспомогательные скрипты (IAP-туннели, утилиты)

```

## 🔗 Связанные репозитории

* **`bug-farm-gitops`** — GitOps-репозиторий (ArgoCD) с манифестами платформенных сервисов (Cilium, Envoy Gateway, Vault, VictoriaMetrics) и приложений.
